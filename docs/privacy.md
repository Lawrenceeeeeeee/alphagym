# 发布边界

GitHub 私有可见性不是上传研究结论的许可。本项目采用更严格的代码发布边界：

- 可上传：源代码、合成测试、方法配置、通用模板、使用文档。
- 不上传：`research/`、研究报告、收益/净值/排名、训练权重、信号和交易记录。
- 不上传：`.env`、账户资料、认证文件、数据湖、调试转储和个人工具会话。
- `legacy/` 及原本地提交历史仅在本地保留；新发布历史不得继承含研究记录的旧提交。

`.gitignore` 只是第一道防线，不能从旧提交中移除文件。发布前应核对实际 Git 树、
可达历史、文件大小及凭据扫描；不要使用 `git push --all` 或 `git push --mirror`。
只推送已经检查过的发布分支到远端 `main`。

自动测试只用合成数据。不要把真实研究结果作为 CI artifact 上传。
配置中的研究期、候选因子与模型参数是方法输入，不构成已验证的收益结论。
